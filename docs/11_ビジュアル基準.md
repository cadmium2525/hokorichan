# ほこりちゃん — ビジュアル基準（v0.5）
基準資料: `10_ピクセルアート設定資料_Ver1.png`（ゲーム全体の見た目はこれに合わせる）

## 共通ルール
- 有料素材なし。人物・家具・ほこりちゃんはすべてコード（Canvas API / Three.js）で生成する。
- 3D画面は低解像度に描いて NearestFilter で拡大（`pixelRenderer.ts`）。UIの人物は `image-rendering: pixelated` で整数倍（32/64/96/128px）表示。ぼかさない。
- 光は左上から。陰影は「明るい・ふつう・かげ・輪郭」の4段階。

## 人物（`src/render/pixelCharacters.ts`）
- 32×32ドットのちびキャラ。丸い頭（体の約半分）、縦長の目＋白いハイライト、ピンクのほっぺ。
- 部品（楕円・矩形）ごとに球/円柱の陰影を付け、外側に1ドットの輪郭（隣の色のいちばん暗い色）。
- 男の子：茶髪・水色シャツ・紺の半ズボン・ピンクの靴／女の子：茶色のボブ・ピンクのワンピース・髪どめ／お母さん：お団子・ラベンダーのワンピース・白いエプロン（ピンクのポケット）。
- 町の人（友だち・友だちのお母さん・店員さん・花屋さん・パン屋さん・おばあちゃん）は同じ体型の色ちがい＋小物（コック帽・メガネ）。
- 向き：正面・背面・左（右は左の鏡像）。
- アニメ（各4コマ）：待機（上下ゆれ・まばたき）／歩き／走り／掃除（ハンディモップ・掃除機・ほうき、素手とぞうきんはしゃがんで拭く）／驚き（！）／喜び（きらきら）／会話／お小遣いを渡す（コイン）。
- まち：移動方向に合わせて向きを変えて歩く。町の人は入口の横に立ち、主人公が近づくとそちらを向く。
- 部屋の掃除：主人公が道具を持って立ち、道具の先が指の位置に来る。動かした方向を向いて掃除アニメ。近景（窓のさん等）は道具だけ。

## ほこりちゃん（`src/render/hokorichan.ts`）
- 本体はクリーム #fffaf2。小房ごとにクリーム・ラベンダー・ピンクの色むら、下側はラベンダーの陰（#e6e0f2〜#cfc6e6）。
- 3段階のトゥーン陰影＋ラベンダーグレーの輪郭（シルエットだけに出る）。

## ホコリ（`createDustPuff`）
- 綿ぼこり＝ふわふわの玉／糸くず＝色糸がからむ／砂ぼこり＝つぶの小山／猫の毛＝細長い毛束／花粉＝つぶつぶの黄色い玉／粉ぼこり＝平たい山。2段階の陰影。

## 部屋・家具（`proceduralArt.ts`）
- 背景・家具パレット：#a0644a #b8754f #d9a06a #e8b48a #f2cbb0 #f8e3cc。
- 壁はクリーム＋木の腰板。家具の木目テクスチャはふちを1ドット暗くして輪郭に見せる。
