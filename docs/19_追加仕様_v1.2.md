# ほこりちゃん — 追加仕様 v1.2（6章 銀河編）
更新: 2026-10-13

## 流れ
1. 5章の山場「太陽系をひと回り」のあと、次にほこりちゃんの所へ帰ると、**銀河ほこり連合**の窓口係さん（新しい人物：水色のはだ・アンテナの宇宙人。いちばん真顔）が来る。
2. ほこりちゃんは**天の川のほとり**（すみか8、容量250000、無料）へ。出来事 `galaxyLetter`・`galaxy`。
3. ホームのボタン「**銀河へ**」で銀河のおそうじ。
4. 成長250000で6章の山場「**銀河団をひと包み**」。出来事 `cluster`。「（6章 銀河編 おしまい。終章は準備中）」。

## 銀河のおそうじ（新しい遊び：かき集める）
- まんなかに大きなほこりちゃん。まわりに**星雲のもや**（1つの星雲＝つぶ40個のかたまり）が浮かぶ。
- 銀河はゆっくり**うずをまいて**いて（反時計回り）、つぶは少しずつ外へ流れていく。
- **指でなでるように動かす**と、指の通り道のつぶがその向きに流れる（指のまんなかほど強く、少しばらける）。ほこりちゃんの口のまわりまでかき集めると吸い込む。
- 始めはどんどん集まり、最後はふちに散ったつぶを追いかける形になる。
- 45秒。つぶ1つでホコリ30（星雲1つで1200）、星雲1つぶんで60コイン（窓口係さんから）。星雲は最大10、60分で満タン。
- かき集めたつぶは0.6秒ごとにまとめてバッグへ入れて保存（つぶごとの保存は重いため）。

## 新しいホコリ・ランク・すみか・アクセサリー
- 星雲のもや：毛並み「ゆらゆら」＝銀河のおそうじで、かき集める指の幅が広がる。毛並み図鑑は 13＋78＝91種類。
- ランク：超巨星級（100000）、太陽系級（130000）、銀河級（170000）、銀河団級（210000）。
- すみか8「天の川のほとり」：星空に、うしろの大きなうずまき銀河と小さな太陽。
- なつかしの味：6章は×50（好物は×100）。
- アクセサリー（6章で入荷）：星雲のはちまき（2500）、銀河のうずまきピン（3200、ゆっくり回る）。
