# ほこりちゃん — ロードマップ案（v0.4以降）
更新: 2026-10-12 / 状態: 案（数値はすべて仮）

## 0. 方針
- **数字を増やすゲームにしない。** ほこりちゃんの規模が上がるたびに「掃除のしかた・場所・相手・物語」が変わる。
- **世界の中では誰も驚かない。** 子供が土地を買っても、ほこりちゃんが地球を包んでも、大人も町の人も真顔で普通に対応する。ツッコむのはプレイヤーだけ。
- **すき間でも、がっつりでも。**
  - すき間：1か所の掃除は1〜2分。開けば何かひとつ進む（ホコリが積もっている／依頼が来ている／ほこりちゃんが何か言っている）。
  - がっつり：場所のはしご、依頼の連続、章のイベント、着せ替え・図鑑うめ。
  - 遊ばない日があっても損をしない（ホコリは満タンで止まる、依頼は数件までたまる、期限で失敗しない）。

## 1. 章立て（規模ごとに遊びが変わる）

| 1 おうち編（いま） | 綿ぼこり〜お部屋級（〜300） | 自宅・友だちの家 | 指でなぞる（素手→掃除機） | 綿ぼこり・糸くず | 家族・友だち | ケースに入らなくなる → 家族会議で「空き地、買えば？」→ コンテナへお引っこし |

各章で「最初は戸惑う新しい遊び → 慣れる → 山場のイベント → 次の章」の形にする。章ごとに成長の上限があり、山場を越えると次が開く。

## 2. 章をまたいで育つ仕組み
### 2.1 ホコリの種類と食べ合わせ（毛並み・技）
- バッグのホコリは種類ごとに数える。あげるホコリを選べる（まとめてあげるも可）。
- 食べた比率で「毛並み」が育ち、見た目と技が変わる。
  - 例：花粉を多く食べる → 黄色っぽくなり「くしゃみ」（掃除中に一度だけ広い範囲を吸う）
  - 猫の毛 → 毛足が長くなり「もふもふ」（引き寄せ範囲が広い）
  - 砂ぼこり → 重く丸くなり「ころころ」（転がる速さアップ）
- **どこを掃除するかに理由ができる**（「猫の毛はおばあちゃんの家にしかない」）。

### 2.2 依頼（掲示板）と評判
- 町の掲示板・電話で依頼が来る（同時に最大3件、期限なし）。
  - 種類指定：「花粉を20個」
  - 早さ：「お客さんが来るから3分以内に玄関を」（失敗しても報酬が減るだけ）
  - 落とし物探し：「指輪をなくした」→ 掃除中にホコリの中から光る物が見つかる → 届けると喜ばれる
- 達成すると **評判** が上がる。新しい場所や依頼主は「評判」で紹介されて開く（お金だけでは開かない）。
- コインは道具・すみか・アクセサリー・土地、評判は場所と人。役割を分ける。

### 2.3 図鑑
- ホコリの種類、見つけた落とし物、出会った人を記録。すき間時間の「ちょっと埋めたい」動機に。

### 2.4 拠点（空き地）
- 空き地 → コンテナ（2章）→ 倉庫（3章）→ 発射場（5章）。
- 拠点は「ほこりちゃんの寝床」と「次の章へ出る基地」。建物ごとに見た目が変わるだけでなく、章の遊びを始める場所になる。

## 3. やらないこと（クリッカー化を防ぐ）
- 指数的に増える数字、放置で増え続ける報酬、ひたすら上がる倍率。
- お金だけで次の場所が開く作り（評判と章の山場で開く）。
- 遊ばない日のペナルティ。

## 4. 次に作るもの（v0.4：1章の締めと2章の入口）— 実装済み（09_追加仕様_v0.4.md）
1. **1章の山場**：成長300に達するとイベント。ケースに入らない → 家族会議 → 空き地を買う → コンテナにお引っこし（容量1000、おうち級へ）。
2. **ホコリの種類**：既存の場所に種類を割り当て（窓のさん＝砂ぼこり、洗濯機＝糸くず など）＋新しい場所で猫の毛・花粉。バッグを種類別に。食べ合わせで毛並みが変わり、技を1つ。
3. **掲示板と依頼**：まちに掲示板。依頼3種（種類指定・早さ・落とし物）と評判。
4. **ほこりちゃんと一緒に掃除**：おうち級から、掃除シーンにほこりちゃんが登場して転がって吸う（指でみちびく）。
5. **商店街**：まちを広げて花屋・パン屋・おばあちゃんの家（評判で順に開く）。

1→2→3→4→5 の順で、1つずつ遊べる状態にしながら進める。
