# ほこりちゃん — 追加仕様 v1.0（4章 地球編）
更新: 2026-10-12 / 08_ロードマップ案.md の 4章。数値は `src/game/catalog.ts`（`HABITATS[6]`・`WORLD`・`EARTH_WRAP_XP`）。

## 1. はじまり：世界ほこり機構
- 梅雨明けのあと倉庫がいっぱい（成長5000）になると、黒い車で**世界ほこり機構の人**（スーツ・メガネ）がやってくる。
- 相棒の新しいおうち「**町はずれの丘**」（容量30000）を機構の費用で用意 → お引っこし（無料）。お母さん「夕ごはんまでには帰ってくるのよ」。
- 丘のすみか画面：広い草原と小さな丘。まわりに小さな家や木を並べて、山のような大きさを見せる（比べる物）。
- ランクに **山級（5000〜）・大陸級（12000〜）・地球級（22000〜）** を追加。

## 2. 世界のおそうじ（地球儀）
- 丘の画面に「**世界へ**」（地域の数を表示）。空のおそうじもそのまま使える。
- 宇宙を背景に、手続き生成の地球儀（海・陸・砂漠・氷のドット絵）と、そのとなりに座る大きなほこりちゃん（頭の上に主人公）。
- **指でなぞると地球儀が回る**（はなすと少し回り続ける）。砂嵐や火山灰の地域を**長押し**（0.9秒）すると、地域が縮んで、ほこりちゃんの口へ吸い込まれる。少し動かすと回す操作に切り替わる（誤操作防止）。
- 地域は満タンで10か所、60分で戻る。遊べるのは45秒（全部吸い込むか「おわる」で終わり）。
- 1地域でホコリ120個（黄砂5：火山灰4：砂ぼこり1）。お礼は世界ほこり機構から1地域25コイン。

## 3. 新しいホコリ：火山灰
- 毛並み「**ほかほか**」：世界のおそうじの長押しが短くてすむ。毛並み図鑑のことばは ほかほか／かざん。掲示板の依頼にも出る（世界ほこり機構「火山灰の標本を各国の博物館に配りたいのです」）。

## 4. 4章の山場：地球をひと回り
- 丘がいっぱい（成長30000）で、ほこりちゃんが地球をそっと抱きしめてふかふかに包む。機構の人「観測史上もっとも空気のきれいな一日です」、お母さん「ちゃんと元の大きさに戻ってから帰ってくるのよ」。4章おしまい（5章「宇宙編」は準備中）。

## 追記（v1.0.2）
### 家具へのめり込み防止（掃除）
- 指で吸い込む点・主人公の立ち位置・一緒に掃除するほこりちゃんを、家具の足もと（当たり判定の四角）の外へ押し出す（`src/game/geometry.ts` の `pushOutOfBlockers`）。家具の上ではホコリがないので、吸い込む点も家具の外。

### 丘へは駅から電車で
- 丘に住んでいるあいだ、「おでかけ」は駅から出発し、下のボタンは「駅から丘へ帰る」。駅に着くと電車で丘へ（「電車にゆられて、町はずれの丘へ……」）。
- 駅の掃除の画面にも「電車で丘へ」ボタン。行き先リストの先頭は駅。

### 思い出の倉庫（空いた倉庫の掃除）
- 丘へ引っこしたあと、まちの倉庫は「**思い出の倉庫**」。行くと掃除場所の画面。
- 内装：壁いっぱいのほこりちゃんの写真（だんだん大きくなる記念写真のドット絵）、歴代の掃除道具の棚（ぞうきん・モップ・掃除機）、むかしのガラスのケース、大きなピンクのクッション。
- ホコリ30（綿ぼこり5：糸くず2：猫の毛1：砂ぼこり1：花粉1）、基本50、60分で満タン。お小遣いはお母さんから。

### 小さくなってついてくる（v1.0.3）
- 丘に引っこしたあとも、まちの掃除でほこりちゃんは一緒に手伝う（毛並みの技もそのまま）。
- 丘に引っこしてから、はじめてまちで一緒に掃除するときに一度だけ：「あれ？ ほこりちゃん、丘にいるはずなのに……」→「ほこりちゃんは、するするっと小さくなってついてきた。お店の人も、いつもどおり『いらっしゃい』と言った」。出来事 `shrink`。
- 4章の山場のお母さん「ちゃんと元の大きさに戻ってから帰ってくるのよ」、終章の小さな綿ぼこり「……まだ、たべられるよ？」へつながる伏線。

### まちの人と話す（v1.0.4）
- まちに立っている人（店員さん・友だち・花屋さん・パン屋さん・おばあちゃん・駅長さん・先生）をタップすると、主人公がその人の横（画面の左右）まで歩いて向かい合い、ひとこと話す。
- タップ判定は、人の胸のあたりを画面に投影した位置から横30px・縦44px以内（板の透明部分が広いので3Dの当たり判定は使わない）。建物より先に判定する。
- セリフは `src/game/talk.ts`。章・梅雨・大会などの出来事に合わせて候補が変わり、遊び方のヒント（猫の毛→もふもふ、チョーク→速く飛ぶ、毛並みはランクが上がるときに決まる、など）をまぜる。同じ人に続けて話しかけても、前回と同じセリフは選ばない。
- 話した人は人物図鑑に記録される。報酬・進行はなし（寄り道の楽しみ）。
