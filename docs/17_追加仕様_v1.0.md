# ほこりちゃん — 追加仕様 v1.0（4章 地球編）
更新: 2026-10-12 / 08_ロードマップ案.md の 4章。数値は `src/game/catalog.ts`（`HABITATS[6]`・`WORLD`・`EARTH_WRAP_XP`）。

## 1. はじまり：世界ほこり機構
- 梅雨明けのあと倉庫がいっぱい（成長5000）になると、黒い車で**世界ほこり機構の人**（スーツ・メガネ）がやってくる。
- 相棒の新しいおうち「**町はずれの丘**」（容量30000）を機構の費用で用意 → お引っこし（無料）。お母さん「夕ごはんまでには帰ってくるのよ」。
- 丘のすみか画面：広い草原と小さな丘。まわりに小さな家や木を並べて、山のような大きさを見せる（比べる物）。
- ランクに **山級（5000〜）・大陸級（12000〜）・地球級（22000〜）** を追加。

## 2. 世界のおそうじ（地球儀）
- 丘の画面に「**世界へ**」（地域の数を表示）。空のおそうじもそのまま使える。
- 宇宙を背景に、手続き生成の地球儀（海・陸・砂漠・氷のドット絵）と、そのとなりに座る大きなほこりちゃん（頭の上に主人公）。
- **指でなぞると地球儀が回る**（はなすと少し回り続ける）。砂嵐や火山灰の地域を**長押し**（0.9秒）すると、地域が縮んで、ほこりちゃんの口へ吸い込まれる。少し動かすと回す操作に切り替わる（誤操作防止）。
- 地域は満タンで10か所、60分で戻る。遊べるのは45秒（全部吸い込むか「おわる」で終わり）。
- 1地域でホコリ120個（黄砂5：火山灰4：砂ぼこり1）。お礼は世界ほこり機構から1地域25コイン。

## 3. 新しいホコリ：火山灰
- 毛並み「**ほかほか**」：世界のおそうじの長押しが短くてすむ。毛並み図鑑のことばは ほかほか／かざん。掲示板の依頼にも出る（世界ほこり機構「火山灰の標本を各国の博物館に配りたいのです」）。

## 4. 4章の山場：地球をひと回り
- 丘がいっぱい（成長30000）で、ほこりちゃんが地球をそっと抱きしめてふかふかに包む。機構の人「観測史上もっとも空気のきれいな一日です」、お母さん「ちゃんと元の大きさに戻ってから帰ってくるのよ」。4章おしまい（5章「宇宙編」は準備中）。

## 5. アクセサリー（4章）
