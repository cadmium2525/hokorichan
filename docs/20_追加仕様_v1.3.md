# ほこりちゃん — 追加仕様 v1.3（終章）
更新: 2026-10-13

遊びは短く、演出が中心の章。

## 流れ
1. 6章の山場「銀河団をひと包み」のあと、次にほこりちゃんの所へ帰ると、世界ほこり機構の人・管制官さん・窓口係さんの**3人がそろって**来る。「宇宙ぜんぶのホコリを」「相棒さんのおうちは宇宙のまんなかに。……もう、ほかに置ける場所がないのです」。お母さん「今日の夕ごはんは、ハンバーグよ」。
2. ほこりちゃんは**宇宙のまんなか**（すみか9、容量600000）へ。出来事 `universeLetter`・`universe`。まわりに、しゃぼん玉になった、よその宇宙がいくつも浮かぶ。
3. ホームのボタン「**しゃぼん玉へ**」。
4. **次元超越級**（成長500000）になって帰ると、一度だけ、ほこりちゃんの大きな顔が**画面の下からボタンの上にはみ出して**のぞく（さわれないので、操作のじゃまにならない）。「……でも、ボタンはちゃんと押せるみたい」。出来事 `peek`。
5. **すべてのほこり級**（成長600000）で、最後の場面（出来事 `finale`）。

## しゃぼん玉の宇宙（新しい遊び：はじく）
- 画面の下に、頭のてっぺんだけ見える、とても大きなほこりちゃん。
- よその宇宙がしゃぼん玉（にじ色のふち、中に小さなうずまき銀河）になって、下から順に浮かんでくる。**タップしてはじく**と、中のちりがほこりちゃんにふりそそぐ。上まで行ったものは、また今度（残りとして数える）。
- 30秒。しゃぼん玉は最大12、1つでホコリ5000・100コイン。60分で満タン。
- 新しいホコリ「よその宇宙のちり」：毛並み「ふしぎ」＝しゃぼん玉がゆっくり浮かぶ。毛並み図鑑は 14＋91＝105種類。
- なつかしの味：終章は×100（好物は×200）。

## 最後の場面
1. お話：「ほこりちゃんは、宇宙をぜんぶ、ふかふかに包みこんだ」「すべての宇宙の、すべてのホコリが、毛並みの中で、きらきら光っている」。
2. 画面がゆっくり（3秒）真っ白になる。
3. まんなかに「もう、これ以上おおきくなれないみたい。」
4. しばらくすると、画面の右下の隅に、小さな綿ぼこり（目だけある）があらわれて、ゆれている。
5. タップすると、ぴょんとはねて、ことばが消え、ほこりちゃんの声で「……まだ、たべられるよ？」
6. 「つづく」で白い画面が消え、「（終章 おしまい。このあと――夢からさめるお話と、2周目――は準備中）」。
- 動きをへらす設定（prefers-reduced-motion）では、フェードやゆれを省く。
