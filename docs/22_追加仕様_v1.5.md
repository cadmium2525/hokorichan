# ほこりちゃん — 追加仕様 v1.5（依頼と評判を最後まで意味のあるものに）
更新: 2026-10-13

## 問題
- 評判は2章（商店街の紹介・大会のおしらせ）でしか使われず、3章からはたまるだけだった。
- 掲示板の依頼は、お礼（約30〜60コイン）も数も1章のまま。後半はコインが何千もあり、依頼の意味がほぼなかった。

## A. 依頼を章に合わせて大きく
- お礼（コイン）と集める数に、章ごとの倍率。

| 章 | お礼 | 集める数 |
| --- | --- | --- |
| 1 | ×1 | ×1 |
| 2 | ×1.5 | ×1 |
| 3 | ×3 | ×2 |
| 4 | ×6 | ×3 |
| 5 | ×10 | ×4 |
| 6 | ×15 | ×5 |
| 終章 | ×20 | ×6 |

- **大きな依頼**（4章から、3割）：その章の依頼主から、その章のホコリをたくさん。評判★2。掲示板ではうすむらさきの札「大きな依頼」。

| 章 | 依頼主 | ホコリ | 数 | お礼 |
| --- | --- | --- | --- | --- |
| 4 | 世界ほこり機構 | 黄砂・火山灰 | 300〜600 | 600 |
| 5 | 宇宙ほこり管制センター | 星くず・宇宙のちり | 1500〜3000 | 1200 |
| 6 | 銀河ほこり連合 | 星雲のもや | 3000〜6000 | 2000 |
| 終章 | 銀河ほこり連合 | よその宇宙のちり | 10000〜20000 | 3500 |

## B. 次の章へ進むには評判も
- 章が切りかわる出来事に、評判の条件を足した（ほかの条件はいままでどおり）。

| 切りかわり | 評判 |
| --- | --- |
| 2章→3章（市役所の手紙・倉庫） | ★12 |
| 3章→4章（世界ほこり機構・丘） | ★30（v1.7で20から変更） |
| 4章→5章（管制センター・月のとなり） | ★45（v1.7で26から変更） |
| 5章→6章（銀河ほこり連合・天の川のほとり） | ★60（v1.7で32から変更） |
| 6章→終章（3つの機関・宇宙のまんなか） | ★75（v1.7で38から変更） |

- 1章あたり、依頼を3〜5件こなすくらい（ほかに大会優勝★3、梅雨明け★5、宝物の場所そろい★1）。
- 詰まないように：ほかの条件はそろって評判だけ足りないとき、ホームに帰ると「次の章へ進むには、評判があと★○。掲示板の依頼をこなそう」。掲示板の評判の下に「（次の章へは ★○）」。
- すでに次の章へ進んでいる保存データには影響しない。
