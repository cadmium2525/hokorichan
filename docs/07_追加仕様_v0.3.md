# ほこりちゃん — 追加仕様 v0.3（まち・PWA）
更新: 2026-10-12 / v0.2（06_追加仕様_v0.2.md）への追加・変更点。

## 1. まち（オーバーワールド）
- 家の「おでかけ」でまちへ出る。斜め見下ろしの町を主人公（ちびキャラ）が歩く。
- 操作：行きたい場所・建物をタップするとそこへ歩く。建物の入口に着くと中に入る。画面外の建物は端に「◀ ショップ」などの札が出て、タップするとそこへ歩く。下の「おうちに帰る」で自宅へ。
- 建物
  - **おうち**：飼育部屋へ戻る。家の中の掃除場所（5か所）は家の中の「おそうじ」から。
  - **ショップ**：掃除用具・すみか（ケース）・アクセサリーを買う。**家からは買えない**（お使い要素）。
  - **友だちの家**：ほこりちゃんが**成長30**になると友だちから電話があり解禁。初回は友だち・友だちのお母さんとの会話。掃除場所は「玄関」（14個・基本20・30分）と「友だちの部屋」（24個・基本30・50分）。お小遣いは友だちのお母さんから。掃除後は友だちの家の前（まち）に戻る。
  - **空き地**：「準備中」。将来ほこりちゃんのコンテナ・倉庫を建てる場所。
- 遊びの流れ：序盤は家とショップを往復して育てる → 途中から友だちの家が開き、家のホコリが積もるまでの間は友だちの家を掃除する。

## 2. PWA
- `public/manifest.webmanifest`、アイコン（いただいたイラスト：192/512/180）、`public/sw.js`。
- ホーム画面に追加すると全画面（standalone・縦向き）で起動。
- サービスワーカー：ページ本体はネット優先（更新をすぐ反映）、スクリプト・画像はキャッシュ優先。一度開けばオフラインでも起動できる。

## 3. 保存データ v3
`version: 3`。追加: `townIntroDone`（まちの説明を見た）、`friendIntroDone`（友だちの家の初回イベントを見た）。v2 からはどちらも未読として引き継ぐ。
