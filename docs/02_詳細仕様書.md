# ほこりちゃん — MVP詳細仕様書 v0.1
更新: 2026-10-12 / 実装担当: Claude Code

## 0. 目的と制約
スマートフォン縦持ちで遊べる、掃除→持ち帰り→餌やり→成長→設備投資の反復を検証するWebゲーム。開発・公開費用0円を優先。Three.js + TypeScript + Vite、外部有料アセット・バックエンド・認証・広告SDKなし。PWA化は後工程。ネット接続は初回ロードのみを想定（キャッシュ導入後）。

## 1. MVPスコープ
含む: 3D斜め見下ろしの1部屋、ホコリ15〜30個、ドラッグ掃除、清掃達成報酬、帰宅ボタン、餌やり、連続成長、ケース拡張3段階、簡易湿気イベント、ローカル保存、チュートリアル、音ON/OFF。
含まない: 友人宅、アルバイト、都市・宇宙マップ、課金、ログイン、オンライン同期、NPC会話、複雑な物理演算。宇宙ランクは将来設計のみ。

## 2. コアループ
1. 清掃シーン: ドラッグで掃除機の吸引範囲を移動しホコリを回収。
2. 清掃達成: 回収率80%以上で報酬を受け取れる（報酬=基本20 + 回収数×2）。回収したホコリはバッグに蓄積。
3. 飼育シーン: 「あげる」を押すとバッグのホコリをすべて与える。1個あたり成長XP+1。リアクション表示。
4. 設備: コインを支払ってケース容量を拡張。容量上限に達したら餌やり不可、掃除は可能。
5. 次の清掃: 部屋のホコリを再配置して繰り返す。報酬は清掃セッションにつき1回。

## 3. 画面とUI
縦画面360×800 CSS px基準、320〜430幅で検証。上部: コイン、バッグ、進捗。中央: 3Dキャンバス。下部: 状況に応じて「掃除完了」「帰宅」「餌をあげる」「ケース拡張」ボタン。タッチ対象44px以上。HUDはHTML/CSSで実装し、WebGL上に文字を描かない。横画面は回転案内を表示。

## 4. 3D/擬似ピクセル描画
Three.js OrthographicCameraを(8,10,8)から原点へ向ける。床・壁・家具はBoxGeometry中心。CanvasTextureは自動生成し、magFilter=NearestFilter、低解像度RenderTarget(例320×568)を拡大。ピクセルパーフェクトより可読性を優先。アンチエイリアス・影は控えめ。pixelRatioは最大1.5、60fps目標、低性能端末では30fpsを許容。

## 5. ホコリちゃん
丸い本体 + 目2つ + 口 + 頬 + 外周の小房をコード生成。表情: idle, happy, eating, damp。成長XPを永続値として保持し、サイズは段階的に増加。MVP表示サイズはケース内での視認性を優先しクランプ。ケース容量を超える給餌は不可。サイズランク例: 0〜19=綿ぼこり級、20〜49=手のひら級、50〜99=ぬいぐるみ級、100以上=お部屋級（将来拡張）。地球級・木星級はロードマップ上の演出目標で、MVPでは実装しない。

## 6. 湿気
セッション開始時に20%の確率で湿気状態（テスト用固定シード可）。湿気中は表示スケール×0.7、色味を暗く、表情を変更。成長XPとケース容量は減らさない。「乾燥させる」無料ボタンで即回復。初期実装はストレスの少ない演出に留める。

## 7. データモデル
```ts
type SaveData = {
 version: 1;
 coins: number;
 dustBag: number;
 growthXp: number;
 caseLevel: 1 | 2 | 3;
 damp: boolean;
 cleanedSessions: number;
 soundEnabled: boolean;
 tutorialDone: boolean;
};
```
初期値: coins=0, dustBag=0, growthXp=0, caseLevel=1, damp=false。ケース容量: [30, 100, 300]XP。アップグレード費用: Level2=80、Level3=220。localStorageキー`hokorichan.save.v1`。データ不正時は初期値へ復旧、保存時は例外を捕捉。バージョン管理を行う。

## 8. 操作仕様
Pointer Eventsでタッチ/マウス共通処理。掃除中はpointerdown→pointermove→pointerupで吸引位置更新。指と吸引点のずれを少し上方向に補正。UI操作中は3D側の入力を無視。回収済みオブジェクトは重複カウント不可。画面外移動時は安全に終了。

## 9. 状態遷移
BOOT→HOME(飼育)→CLEANING→RESULT→HOME。HOME内でFEED、UPGRADE、DRYのアクション。RESULTは報酬確定を一度だけ実行。画面切替でThree.jsのメッシュ・イベント・アニメーションを適切に解放。

## 10. 受け入れ条件
- Android Chrome / iOS Safariで縦画面の基本ループが成立する。
- ホコリを集めるとバッグ数が増え、同じホコリを二度回収できない。
- 掃除報酬は同じセッションで重複獲得できない。
- 餌やりでバッグ数が減り、成長XPが増え、見た目が大きくなる。
- ケース上限と購入コストが正しく動作する。
- 湿気でXPが減らず、乾燥で見た目が復帰する。
- リロード後に進行が保存される。
- オフライン対応前でもクラッシュせず、初回ロード後の操作に外部APIを要求しない。
- `npm run build`が成功し、TypeScriptエラーがない。

## 11. 将来拡張
友人宅→清掃バイト→清掃会社→都市→地球→木星。巨大化は実寸3D化ではなく、ランク・背景・カメラ演出でスケール感を表現。個別のマップ/経済バランスはMVP検証後に決定。
