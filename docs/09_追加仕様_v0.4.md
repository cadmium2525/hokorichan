# ほこりちゃん — 追加仕様 v0.4（1章の山場・2章ご近所編の入口）
更新: 2026-10-12 / 08_ロードマップ案.md の「4. 次に作るもの」1〜5 を実装。数値は `src/game/catalog.ts`。

## 1. 1章の山場：空き地とコンテナ
- ケース（大）が満杯（成長300）になると **家族会議**（「空き地が売りに出てたわよ。お小遣いで買ってきたら？」）。
- まちの空き地で「売地」を **400コイン** で買う → コンテナが届く → すみか「空き地のコンテナ」（容量1000、おうち級）。2章へ。
- 2章では、ほこりちゃんのいる場所は空き地のコンテナ。まちの「ほこりちゃんの所へ帰る」で戻る。

## 2. ホコリの種類と食べ合わせ（毛並み）
| 種類 | 主な場所 | 毛並み（割合15%以上・食べた量20以上で現れる） |
| --- | --- | --- |
| 綿ぼこり | 自分の部屋・本棚・リビング | ふつう |
| 糸くず | 洗濯機のフィルター | カラフル（見た目） |
| 砂ぼこり | 窓のさん・友だちの玄関 | ころころ：一緒の掃除で転がるのが速い |
| 猫の毛 | 友だちの部屋・おばあちゃんの家 | もふもふ：一緒の掃除で吸い寄せる範囲が広い |
| 花粉 | 花屋さん | くしゃみ：一緒の掃除で1回だけ広い範囲を吸い込む |
| 粉ぼこり | パン屋さん | さらさら：湿気にくい |
- バッグは種類別。「餌をあげる」で種類を選んであげる（ぜんぶも可）。食べた割合で毛の色も少しずつ染まる。

## 3. 掲示板・依頼・評判
- まちの掲示板。依頼は20分ごとに1件届き、最大3件（遊ばない間もそれ以上たまらない、期限なし）。
- 種類：**種類指定**（バッグのホコリをわたす）、**早さ**（その場所を○秒以内に掃除完了）、**落とし物**（その場所のホコリにまぎれた物を道具で見つける）。
- 報酬はコイン＋**評判★**。商店街の場所は評判で紹介される（花屋さん★0、パン屋さん★4、おばあちゃんの家★8。いずれも2章から）。
- 町の人は真顔でホコリを欲しがる（「花粉を集めて新しい品種を」「猫の毛でフェルト人形を」）。

## 4. ほこりちゃんと一緒に掃除（2章から）
- 掃除シーンにほこりちゃんが登場。指でなぞるとついてきて、離すといちばん近いホコリへ転がって吸い込む。
- 毛並みで能力が変わる（上表）。落とし物はほこりちゃんは拾わない（自分で見つける）。

## 5. 商店街
- まちの南に通りを追加：花屋さん（花粉）、パン屋さん（粉ぼこり）、おばあちゃんの家（猫5匹・猫の毛）。お小遣いはそれぞれの店の人から。

## 追記（v0.5.1）：コンテナに引っこした後の家の掃除
- コンテナ（空き地）にいるときは「おそうじ（家の中）」ボタンを出さない。
- 家の掃除は、まちの「おうち」に入ると場所を選べる（タイトル「おうち：どこを掃除する？」）。
- 終わったら、まちの「おうち」の前に戻る。ほこりちゃんの所へはまちから帰る。
- お引っこしのお話でお母さんが「おうちの掃除も、帰ってきたときにお願いね」と伝える。
