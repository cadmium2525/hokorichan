# 開発用ページ（dev.html）
公開URLの `dev.html`（例：`https://cadmium2525.github.io/hokorichan/dev.html`）。ローカルは `npm run dev` のあと `/dev.html`。

- **ゲームのタブは閉じてから使う**（開いたままだとゲーム側の保存で上書きされる）。同じブラウザの保存データ（localStorage）を書きかえる。
- **場面へジャンプ**：章や山場の直前の保存データを作る（主人公は男の子/女の子を選べる）。例：家族会議の直前、大会のおしらせ直前、市役所の手紙の直前、梅雨の直前、梅雨中・届け物そろい、3章クリア後。
- **すぐ足す**：コイン+1000、ホコリ全種+50、評判+5、道具・アクセサリーぜんぶ、掃除場所/空の雲を満タン、大会の待ち時間を消す、依頼をすぐ届く状態に、乾かす、図鑑をぜんぶ埋める、すみかいっぱいまで成長。
- **数値を書きかえる**：コイン・成長・評判・すみか・しっとり・バッグ・出来事（チェックボックス）。
- **保存データ（JSON）**：直接編集、ファイルへの書き出し・読み込み、保存を消す。おかしな値はゲームと同じ仕組みで直してから保存する。
- 「ゲームを開く（時間60倍）」は `?fast=1`（ホコリ・依頼・空の雲が60倍で回復）。`?damp=0` で湿気なし、`?seed=123` でホコリの配置を固定。
- 場面は `src/dev/presets.ts`。新しい山場を作ったら、ここにも直前の場面を足す（`tests/presets.test.ts` で起きる状態か確認）。
