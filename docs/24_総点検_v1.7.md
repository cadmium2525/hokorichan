# ほこりちゃん — 総点検（v1.7）
更新: 2026-10-13

サブエージェント4つ（進行とバランス／画面の流れ／3D画面のコード／ブラウザで実際に遊ぶ）で全体を点検し、見つかったものを直した。

## 直した不具合
- **大きな依頼の数が、読み直すと999になっていた**（保存の上限が999）。上限を10万に。
- **一度に最後まで育つと、最後の場面のあとに「はみ出す」場面が出た**。はみ出しを先に。お話を見終わってから記録し、そのあと最後の場面へ。
- **すみかがいっぱいになっても、章の出来事はおでかけして帰るまで起きなかった**。餌をあげたあと、その場で出来事を確かめる。しっとりのお知らせがあっても出来事は先に。
- **端末の時計が進んでいた保存データでは、依頼が何日も届かなかった**。依頼の時計を「今から1回分」までにおさえる。
- **新しい版で作った引き継ぎコードを読むと、白紙のデータになった**。読み込まずに「新しい版のゲームで作ったコードみたい」。
- **宇宙・世界・空・銀河で、最後に吸いこんだもの（とちゅうのもの）がお礼に数えられなかった**。吸いこみ終わるまで待ってから終わる（時間切れのあとは最大1.5秒）。
- **お話の画面で「図鑑」「？」を押すと、お話が消えて二度と出ないことがあった**（大会優勝の任命式など）。お話・確認・結果などの画面が出ているあいだは、その画面のボタンだけ受けつける（音のON/OFFはいつでも）。
- **お話の画面の下にはみ出した下のボタンが押せて、裏で別の遊びが始まることがあった**。同上。
- **時間で終わる遊びのとちゅうで図鑑を開くと、そのあいだも時間が進んだ**。図鑑・遊び方はホームとまちでだけ開く。
- **引き継ぎで、前に作った古いコードが出ていた**。開くたびに作りなおす。まちがったコードのときも、貼りつけた文字は残す。
- **「駅から丘へ帰る」のとちゅうで別の建物へ行くと、あとで駅に着いたときに勝手に帰ってしまった**。どこかに着いたら「帰る」は終わり。
- 最後の場面の「つづく」を2回押せた／消えていくあいだ白い画面がタップをふさいでいた。
- 掃除の「全部集めたら自動で完了」が、ちょうど画面が出ているときに来ると消えていた。
- 3D：ほこりちゃんの毛の並べ方のバッファ、空・世界の背景の絵を、場面を閉じても手放していなかった（行き来するたびに少しずつメモリが増えた）。
- 3D：指を離したお知らせが届かなかったとき（アプリを裏にしたときなど）、宇宙・銀河・世界・空で操作できなくなることがあった。新しい1本目の指で、前の指は終わりにする。
- 3D：大きくなったほこりちゃんに、ごはんや「やったー」のキラキラが小さすぎた。大きさに合わせる。しゃぼん玉は、見えている位置で当たりを判定。

## 進行とバランス
- **大会に勝てないと3章へ進めなかった**。初優勝の前に負けが続くと、3回目からほかのチームが少しずつ弱くなる（最大で4割まで）。優勝したあとは元の強さ。保存データに `contestLosses`。
- **こなせない依頼で掲示板が3件うまったままになりうる**。依頼に「ことわる」（評判は下がらない）。
- **評判の条件がほぼ効いていなかった**（ふつうに依頼をこなすと章の初めから越えていた）。★12/20/26/32/38 → **★12/30/45/60/75**。
- **3章が長すぎた**（ぜんたいの3分の1）。なつかしの味を3章から少しだけ（×2）。
- **4章の「世界へ」が町の掃除より弱かった**。地域1つのホコリ 120 → **300**。
- 2章・3章おしまいの文に、評判の条件も書いた。2周目以降の「とばす」の案内は周回数を言わない。
