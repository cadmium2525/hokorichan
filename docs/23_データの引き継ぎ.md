# ほこりちゃん — データの引き継ぎと保護（v1.6）
更新: 2026-10-13

サーバー・ログインなし（0円）のまま、データが消えにくく、別の端末へ持っていけるようにする。

## 引き継ぎコード
- 「あそぶ」→「引き継ぎ」。はじめて開いた端末では、主人公をえらぶ画面の「引き継ぎコードで続きから」。
- **引き継ぎコードを作る** → 「コードをコピー」（コピーできない端末では、コードを選んだ状態にして長押しでコピーしてもらう）。
- **コードで続きから**：貼りつけて「このコードで続きから」→ ランク・すみか・コイン・バッグを見せて確認 →「続きから」で、いまの端末のデータを上書きして読み直す。
- 形式：`HK1z.<本文>.<チェック>`。セーブデータ（JSON）を deflate で圧縮し base64url にしたもの。最後の8けたは CRC-32 で、コピーのとちゅう切れや打ちまちがいを見つけて読み込まない。改行や空白がまじっても読める。
- 長さは1000〜2000文字くらい（手で打たずにコピー＆ペースト）。
- 読み込むときは、ふだんの読み込みと同じ `sanitize` を通す（古い版のコードも今の版に整える）。
- 実装：`src/game/transfer.ts`（`encodeSave`・`decodeSave`）。

## データを消されにくくする
- はじめのお話が終わったら、ブラウザに `navigator.storage.persist()` で「このデータは消さないで」とおねがいする。
- ホーム画面に追加して遊んでいない人には、掃除を3回したあとに一度だけ「ホーム画面に追加すると、データが消えにくくなるよ（「あそぶ」→「引き継ぎ」でバックアップも）」。
