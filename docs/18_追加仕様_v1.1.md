# ほこりちゃん — 追加仕様 v1.1（5章 宇宙編）
更新: 2026-10-13

## 流れ
1. 4章の山場「地球をひと回り」のあと、次にほこりちゃんの所へ帰ると、**宇宙ほこり管制センター**の管制官さん（新しい人物・図鑑に載る）がパラシュートで丘に降りてくる。
2. 「木星のまわりに星くずがたまって困っています」→ ほこりちゃんは**月のとなり**（すみか7、容量80000、無料）へお引っこし。出来事 `spaceLetter`・`space`。
3. ホームのボタン「**宇宙へ**」で宇宙のおそうじ。
4. 成長80000（月のとなりがいっぱい）で5章の山場「**太陽系をひと回り**」。出来事 `solar`。「（5章 宇宙編 おしまい。6章「銀河編」は準備中）」。

## 宇宙のおそうじ（新しい遊び：軌道に乗せる）
- ほこりちゃんは、まんなかの星（木星。太陽級になってからは太陽）のまわりを**自動で回る**。
- **指をおいた所の軌道へ移る**（指を動かすと追いかける。はなしてもその軌道を回り続ける）。いまの軌道は白い線、移る先はピンクの点線。
- **内側の軌道ほど速く回る**（ケプラーの法則ふう。いちばん内側で約5秒、いちばん外側で約17秒で1周）。
- 通り道の**星くずの群れ**に近づくと吸い込む。群れは軌道の範囲（半径3.2〜8.0）に散らばり、4割は**小惑星帯**（半径5.2〜6.2）の中。
- 小惑星帯の岩はそれぞれの速さで回っていて、ぶつかると「ごつん」と1.2秒ゆっくりになる（取りこぼしはない）。
- 45秒。群れ1つでホコリ300、お礼40コイン（管制官さんから）。群れは最大12、60分で満タン。
- 太陽級（成長60000〜）になると、まんなかが太陽になり、外側を小さな惑星が回る。

## v1.1.1 宝物と図鑑のタブ
### 宝物（これまでの掃除場所に行く理由）
- 掃除場所ごとに3つ、合計39個の「宝物」（思い出の品）が眠っている（例：窓のさん＝セミのぬけがら・ガラスのおはじき・色あせた切手、思い出の倉庫＝ケース（小）の値札 ほか）。
- よく積もった場所（積もり具合60%以上）を掃除すると、50%の確率で、まだ見つけていない宝物が1つホコリにまぎれる（キラッと光る）。落とし物の依頼が来ている場所では依頼が優先。
- 拾うと図鑑に記録して30コイン。その場所の3つがそろうと評判★+1。
- おそうじの場所えらびに「宝物 n/3」を表示（そろうと緑）。
- 保存は図鑑の `items` に一緒に入れる（版は5のまま）。

### 図鑑のタブ
- 「毛並み・ホコリ・宝物・町の人」のタブに分けた。タブに見つけた数を表示。タブはスクロールしても上に残る。
- 宝物のタブは掃除場所ごとに並べ、最後に掲示板の落とし物。ホコリのタブには毛並みの効果も書いた。

## v1.1.2 なつかしの味と、昼と夜
### なつかしの味（昔の掃除場所で育てる理由）
- 町の掃除場所だけで集まるホコリ（綿ぼこり・糸くず・猫の毛・花粉・粉ぼこり・すす・チョークの粉）は、4章から「なつかしの味」。1個で**4章は×10、5章は×20**育つ。
- 空・世界・宇宙でもたくさん集まる黄砂・砂ぼこり・火山灰・星くず・宇宙のちりは対象外（大きな遊びの量が何十倍にならないように）。
- **きょうの好物**：なつかしの味から毎日1つ（現実の日付で変わる）。さらに×2。餌の画面の上に表示し、各ホコリに「なつかしの味 成長×10」「きょうの好物 成長×20」の札。
- 毛並み（食べたものの割合・ランクごとの毛並み）は**育った量**で数える。後半でも、町のホコリで純わたぐも毛並みなどを狙える。
- いっぱい近くでは、必要な個数だけ食べて容量で止まる（あまりはバッグに残る）。
- 餌をあげたとき「なつかしの味！ ○個で 成長+○」。

### 昼と夜（現実の時刻とつなぐ）
- 端末の時刻で、朝（5〜9時）・昼（9〜16時）・夕方（16〜19時）・夜（19〜5時）。ホームとまちの空の色と光が変わる。夕方と夜は、まちの建物の入口に明かりがともる。
- 夜10時〜朝6時は、ほこりちゃんがねむっている（Zzz）。タップで起き、15秒ほうっておくとまたねむる。餌をあげると起きて食べる。遊びは何も止めない。
- 開発用：URLに `?hour=23` などで時刻を決めて確かめられる。
