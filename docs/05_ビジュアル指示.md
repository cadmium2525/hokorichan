# ビジュアル指示書 v0.1

添付の`04_コンセプトボード.png`は**方向性の参考**。文字やUI、比率をそのまま再現しない。AI生成画像のため表記・寸法・実装可能性は仕様書を正とする。

## 色・雰囲気
暖色の木製家具、クリーム、淡いピンク、ラベンダー。少ない色数と読みやすいシルエット。やさしい、清潔感のある、少し不思議な世界。

## ホコリちゃん
丸い綿毛状の生き物。小さな黒目、短い口、淡い頬。体積が増えても顔のパーツは小さく保ち、かわいさを維持。湿気時は縮み・色変化・しょんぼり顔、乾燥時は復活アニメ。

## 画面構成
掃除: 斜め見下ろしの部屋、ホコリを見つけやすい床、掃除範囲の軽い強調。飼育: ホコリちゃんを主役に大きく表示、ケースの縁と容量表示、給餌ボタン。UI: タップ領域44px以上、下部セーフエリアを確保。

## 禁止事項
リアルな汚れ表現、ホラー風の表情、過剰な点滅、極小文字、素材の無断流用、画像生成結果の文字をゲームUIとして使用すること。
