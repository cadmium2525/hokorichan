# ほこりちゃん — 追加仕様 v1.4（夢オチと2周目）
更新: 2026-10-13

## 流れ
1. 最後の場面（「……まだ、たべられるよ？」）の「つづく」のあと、「（終章 おしまい。遊んでくれて、ありがとう！）」と、えらぶ画面。
   - **夢からさめる（2周目へ）**
   - **もう少し（ゆめの中で遊ぶ）**：そのまま遊べる。ホームに「夢からさめる」ボタンが出て、いつでも2周目へ行ける。
2. 夢からさめると、勉強机の上から。お話「…………」→お母さん「いつまで寝てるの！ 朝ごはんよー！」→「……ゆめ？」→ 机の上に小さな綿ぼこり。目をあけて、ちょっとわらった気がした → 「ポケットの中には、ゆめの中で集めたホコリが、なぜか残っていた。図鑑も、そのまま。」→「また、いっしょに大きくなろうね。……今度は、どこまで？」

## 引き継ぐもの・はじめからのもの
| 引き継ぐ | はじめから |
| --- | --- |
| バッグのホコリ（種類別） | コイン |
| 図鑑（ホコリ・宝物と落とし物・町の人・毛並み） | 道具（素手から） |
| アクセサリー（付けているものも） | すみか（勉強机の上から）・成長 |
| 形（まんまる・おもち など） | お話（出来事）・評判・依頼 |
| 主人公・音の設定・大会の自己ベスト | 掃除場所・空・地球・宇宙・銀河・しゃぼん玉の積もり具合、食べたもの |

- 保存データに `loop`（夢からさめた回数）。ホームの「勉強机の上・2周目」のように表示。3周目以降も同じ。
- バッグのホコリが残っているので、すみかが広がればすぐに育つ（強くてニューゲーム）。ケースはお店で買う、コンテナからはお話で進む、のは同じ。

## お話を飛ばす
- 2周目からは、どのお話にも「**とばす**」ボタン。飛ばした場面の演出（目を覚ますなど）は結果だけ反映する。
